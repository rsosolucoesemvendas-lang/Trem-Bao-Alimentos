Proposta de sistema de gestão feita sob medida pra **Trem Bão Alimentos**.

**Obrigatórios** (todos precisam estar juntos):

- `index.html` → página inicial com os 3 cards
- `apresentacao-trem-bao.html` → apresentação do sistema
- `trem-bao-flow.html` → telas do sistema (mockups)

## 🚀 Como subir no GitHub Pages (passo a passo)

### Passo 1: Criar o repositório
1. Entre em [github.com](https://github.com) e faça login
2. Clique em **New repository** (canto superior direito)
3. Nome do repositório: `trembao-flow` (ou o que preferir)
4. Deixe marcado como **Public**
5. Clique em **Create repository**

### Passo 2: Subir TODOS os arquivos
1. Na página do repositório, clique em **uploading an existing file** (aparece em azul)
2. Arraste os **6 arquivos obrigatórios** de uma vez pra dentro da caixa:
   - `index.html`
   - `apresentacao-trem-bao.html`
   - `trem-bao-flow.html`
   - `orcamento-trem-bao.html`
   - `logo-fita.jpeg`
   - `logo-bordo.jpeg`
3. No campo de commit lá embaixo, escreva algo como `primeira versao` e clique **Commit changes**

### Passo 3: Ativar GitHub Pages
1. Ainda no repositório, clique em **Settings** (menu do topo)
2. No menu esquerdo, clique em **Pages**
3. Em "Source", selecione **Deploy from a branch**
4. Em "Branch", escolha **main** e deixe **/(root)** — depois clique **Save**
5. Espere 30–60 segundos. A página vai aparecer em:
   - `https://SEU-USUARIO.github.io/trembao-flow/`

Pronto! Esse é o link que você manda no WhatsApp.

## 📱 Compartilhar no WhatsApp

Depois de publicado, você manda o link no WhatsApp. Ele vai gerar automaticamente um preview com:
- 🐷 O porquinho da Trem Bão (logo)
- 🔴 Título: "Trem Bão Flow — Proposta pra Trem Bão Alimentos"
- 📝 Descrição: "Sistema de gestão feito sob medida..."

Se o preview **não aparecer na primeira vez**, aguarde uns minutos. O WhatsApp cacheia a primeira visualização — pode demorar pra atualizar.

**Pra forçar atualização do preview:** use uma ferramenta como [debugger.inspector-meta.com](https://meta-tags.io) colando seu link.

## 🔧 Resolução de problemas

**"As imagens não aparecem"**
→ Os arquivos `logo-fita.jpeg` e `logo-bordo.jpeg` não foram enviados junto. Suba os dois no repositório.

**"Clico nos cards e dá erro 404"**
→ Os 3 arquivos de apresentação não foram enviados. Confira que tem `apresentacao-trem-bao.html`, `trem-bao-flow.html` e `orcamento-trem-bao.html` no repositório.

**"O link do WhatsApp mostra texto cru, sem preview"**
→ Aguarde alguns minutos. WhatsApp leva um tempo pra ler as meta tags. Se ainda não aparecer após 10 min, confirme que `logo-bordo.jpeg` está no repositório (ele é a imagem do preview).
